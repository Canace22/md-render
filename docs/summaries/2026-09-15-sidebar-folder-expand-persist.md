# 文档目录记住上次展开的文件夹

日期：2026-09-15

## 现象

侧边栏「文档目录」里展开过的文件夹，一切到今日速记、收起父文件夹，或重启应用，都会全部合上。

## 根因

每个 `TreeNode` 用组件内 `useState(false)` 记展开。子节点只在父文件夹打开时才挂载，所以：

- 收起父文件夹再打开，嵌套展开丢了
- 切走 `paper/folder/graph` 再回来，整棵树重挂，展开丢了
- 重启后更不会回来

## 改动

把展开的文件夹 id 写进 `useEditorStore.expandedFolderIds`，并走现有 persist：

- localStorage key：`md-renderer-sidebar-expanded-folders`
- SQLite key：`sidebar_expanded_folders`（已加进 `EDITOR_STATE_KEYS`）

搜索、以及状态/平台/标签这类临时筛选，只在界面上撑开文件夹，不写进持久化列表。文档类型（文档/图片/视频）是常驻筛选，不能当成「新筛选」把当前可见文件夹全部记成展开——否则每次启动都会全部打开。

「展开/收起全部」才写 store，下次打开也生效。

## 验证

建议手动过一遍（未跑单测 / E2E）：

1. 展开两个嵌套文件夹，切到今日速记再回来，仍是展开的
2. 收起父文件夹再点开，里面刚才展开的子文件夹还在
3. 重启应用后，展开状态还在
4. 点「收起全部」，全部合上；再重启，仍是合上
5. 点「展开全部」，全部打开；再重启，仍是打开
6. 搜索时目录临时全展开；清掉搜索词，回到搜索前的展开
7. 侧边栏常驻「文档」筛选时，重启不会把文件夹全部打开
8. 点文件夹仍会选中该节点
9. 隐藏的 `.agent` 目录不进展开列表
10. 删掉一个已展开的文件夹，不会因为残留 id 报错
11. Web / Electron 都能记住（Web 走 localStorage，Electron 走 SQLite）
