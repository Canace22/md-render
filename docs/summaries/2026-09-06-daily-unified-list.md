# 今日速记：任务 / 笔记 / 事件合并为一个列表，用类型 Tag 区分

## 背景

今日速记原本把一天的内容拆成三张卡片（今日任务 / 笔记 / 事件），每张卡片各带一套头部、
计数、添加入口和空态。实际使用中三块内容量都不大，三张卡片带来三段留白与三次视线跳转；
「今天到底有几件事」还得自己把三个数字加起来。

这次把三种类型合并成 **「今日记录」一个列表**，行首用**类型标签**（任务 / 笔记 / 事件）区分，
顶部补一排类型筛选，需要单看某一类时再切。

## 合并后的规则

**排序**（`compareDailyItems`）：未完成在前、已完成沉底 → 任务 → 事件 → 笔记 → 任务段内按
优先级（高 / 中 / 低）→ 同优先级按 `createdAt`。等价于原来三块各自的顺序，只是首尾相接成一列。

**新建**：右上角「+」改为下拉，选任务 / 笔记 / 事件；草稿行首带类型标签，任务可选优先级，
任务 / 笔记可选类别（事件仍无类别，与数据模型一致）。若当前筛选会挡住新建的类型，自动切到该类型。

**筛选**：顶部 `Segmented`，全部 / 任务 / 笔记 / 事件，各带条数。

## 顺带统一的交互（原来按类型不一致）

| 能力 | 改前 | 改后 |
|------|------|------|
| 复制 | 仅任务 / 笔记 | 三种类型都可复制 |
| 单条改日期（行内 DatePicker） | 仅任务 / 笔记 | 三种类型都可改 |
| 批量改日期 | 仅「笔记」卡片 | 整个列表可批量选中改日期 |
| 行内编辑按钮文案 | 任务/笔记/事件是 save / cancel / delete，待办池是中文 | 统一为 保存 / 取消 / 删除 |

数据模型（`dailyWorkspace.js`）、store 动作、carryOver 语义**未改动**，
`moveDailyEntryItem` 本身对三种类型通用。

**建议人工过一遍（合并列表相关）：**

1. 空白一天 → 列表显示「今天还没有记录」空态，不显示筛选条
2. 「+」→ 任务 / 笔记 / 事件，草稿行类型标签正确，placeholder 与类型匹配
3. 草稿留空点「删除」→ 草稿消失，不落盘
4. 三种类型各加一条 → 顺序为 任务 → 事件 → 笔记，各带类型标签
5. 勾完任务 → 该任务沉到列表底部
6. 筛「笔记」时点「+」→ 选任务，筛选自动切到「任务」，草稿可见
7. 类别下拉：任务 / 笔记有，事件没有；优先级点只出现在任务
8. 单条改日期：三种类型都能改，改完当天列表少一条
9. 批量改日期：跨类型多选 → 一次移走，退出批量模式
10. 待办池：新建 / 加入今天 / 移除 / 改类别，与改前一致
11. 暗色主题下类型标签与类别标签都可读，颜色不打架
