# 产品功能说明

> 这份文档回答一个问题：**打开这个 app，我能干什么。**
> 按左侧栏的实际入口组织，每节写清「能干什么 / 怎么进入 / 需要知道的细节」。
>
> 面向使用者。要看架构和代码入口，见 [ARCHITECTURE.md](../ARCHITECTURE.md) 和 [AGENTS.md](../AGENTS.md)。

## 一句话定位

本地优先的中文内容创作工作台，把 **安排 → 收集 → 写作 → 改写 → 定稿 → 发布** 串成一条路径。
有 macOS 桌面版（Electron）和 Web 版，两者能力有差别，文中会标注。

## 界面地图

左侧竖排图标栏是全部入口，共 9 个界面 + 1 个常驻 AI 助手：

| 入口 | 干什么 |
|---|---|
| 创作首页 | 今天该动哪篇稿子——最近稿件、待办选题、待整理素材、待发布 |
| 今日速记 | 今天的任务、笔记、日程、待办池 |
| 文档 | 写作主战场：编辑器 + 预览 + 目录 + 元数据 |
| 画布工作台 | Excalidraw 无限白板，理选题和素材关系 |
| 图谱视图 | 双向链接关系图 |
| 搜索 | 全文搜索（桌面版走 SQLite FTS5） |
| 发布队列 | 待发布稿件排期与发布前检查 |
| 设置 | 排版模板、发布平台、本地项目目录、工作区导入导出 |
| AI 助手 | 常驻右侧，能对话也能直接操作界面 |

---

## 1. 创作首页（总览）

**能干什么**——进 app 第一眼看的地方，四张卡片回答「现在该干嘛」：

- **最近稿件** —— 最近动过的文档
- **待办选题** —— 还停在 `idea` / `collecting` 的选题
- **待整理素材** —— 素材收件箱里没归位的东西
- **待发布稿件** —— 已经 `ready` 但还没发的

顶部四个快捷动作：**新建稿件**、**新建选题**、**整理素材**、**发布排期**。

**怎么进入**：侧栏「创作首页」，或 AI 助手里 `/工作区概览`。

---

## 2. 今日速记（Daily）

**能干什么**——按日期管理今天的事。任务、笔记、事件放在「今日记录」同一个列表里，行首用**类型标签**区分；右边是独立的待办池：

- **任务** —— 支持优先级（高 / 中 / 低）和类别（工作、创作、学习、生活、个人）
- **笔记** —— 当天的零散记录
- **事件** —— 会议、约定、临时安排
- **待办池** —— 不绑定具体某天、跨天保留的池子

**需要知道的细节**：

- 今日记录列表顶部可按类型筛选（全部 / 任务 / 笔记 / 事件），并支持批量改日期。
- 切换日期只是**换个视图看**，不会动数据。
- 真正跨到新的一天时会跑一次**结转（carryOver）**，把昨天没做完的带过来——这是破坏性操作，只在真跨天时触发一次。
- 桌面版可以同步到本地磁盘。

**怎么进入**：侧栏「今日速记」，或 AI 助手 `/今日任务`、`/今日笔记`、`/待办池` 直接往里加条目。

---

## 3. 文档（写作主界面）

### 编辑与预览

- 自研 CommonMark / GFM 解析渲染：标题、列表、引用、表格、删除线、图片、链接
- 实时预览、编辑 / 预览切换、目录（TOC）面板
- 代码块 Shiki 语法高亮，一键复制
- Mermaid 图表预览与全屏查看
- 浅色 / 深色 / 跟随系统主题
- 纸张感排版：界面退后，正文优先（设计取向见 [editor-philosophy.md](./editor-philosophy.md)）

### 选中文字的 AI 动作

选中一段话会浮出快捷条，9 个动作：**压缩、扩写、润色、标题建议、改语气、提炼要点、小标题、续写、提纲**。

### 稿件元数据

每篇稿件带一组创作属性：

- **状态**：`idea`（选题）→ `collecting`（收集中）→ `draft` / `drafting`（草稿 / 写作中）→ `revising`（修改中）→ `ready`（待发布）→ `published`（已发布）
- **目标平台**、**摘要**、**计划发布时间**
- **关联文档**与**来源素材**（`sourceMaterialIds`，派生稿件会记住是从哪些素材来的）

侧栏可按状态、平台、文档类型、标签筛选。

### 文件树与标签页

- 侧栏文件树，Obsidian 风格多标签页
- 新建文件 / 文件夹、导入为新建 Markdown、导出当前文档

### 非 Markdown 文件

可以直接预览：图片（png/jpg/gif/svg/webp/bmp/ico）、音频（mp3/wav/flac/aac/ogg）、视频（mp4/mov/webm）、表格（xls/xlsx/csv）、网页（html/htm）、json。

可以转成 Markdown：docx、html、csv、txt、rst、org 等。

---

## 4. 画布工作台

**能干什么**——Excalidraw 无限白板，用卡片理选题和素材之间的关系。

- 手绘白板全部能力（图形、连线、自由绘制）
- 把工作区条目作为卡片插入
- AI 助手可以直接往画布**追加卡片**（`/白板卡片`）或**生成流程图**（`/白板流程图`）
- 场景自动防抖保存

**怎么进入**：侧栏「画布工作台」。

---

## 5. 图谱视图

**能干什么**——把双向链接关系画成图。

- 写 `[[文档名]]` 建立链接，图谱里就会出现连线
- 支持显式的 `relatedIds` 关联边
- 滚轮缩放、拖动节点、双击重置

**怎么进入**：侧栏「图谱视图」。

---

## 6. 搜索

- **桌面版**：SQLite + FTS5 全文索引，搜正文内容
- **Web 版**：基于 `localStorage` 的关键词搜索

AI 助手也能调 `search_docs` 帮你搜，或用 `/相关旧文` 召回和当前文档相关的历史稿件。

---

## 7. 发布队列

**能干什么**——统一看待发布的稿件：

- 待发布稿件列表、已排期数量、平均进度
- 平台标签
- 发布前检查清单

**发布平台**：内置掘金、微信公众号、小红书；设置里可以自己增删平台。

---

## 8. 设置

- **排版风格** —— 微信公众号模板：默认简约、InfoQ 风格、暗黑风格、掘金技术风
- **发布平台** —— 增删自定义平台
- **本地项目目录（桌面版）** —— 打开本地文件夹作为工作区，`.md` 直接落盘；
  「从磁盘同步」把外部改动拉回编辑器，冲突有专门的处理弹窗。
  多端同步与版本历史交给该目录自己的 Git 仓库，app 内不再做同步。
- **数据存储（桌面版）** —— 把编辑部记忆、Daily、白板、内置文档迁到 `~/Documents/MdRender` 下的真文件（先只读预演、出报告，确认后才迁移，可以切回旧存储）；从当前内容重建索引
- **外部 agent 接入（桌面版）** —— 内容库路径、复制 MCP 配置、打开 / 重新生成内容库的 `AGENTS.md`
- **备份（JSON）** —— 导出当前工作区为 JSON、导入工作区 JSON

## 9. AI 助手（常驻右侧）

这是这个 app 和普通 Markdown 编辑器差别最大的地方：**它不只是聊天，能直接操作界面**。

### AI 来源：本机 agent 或 API 服务商

- **本机 agent（桌面版，开箱即用）**：自动检测 Codex、Claude Code、Cursor，默认按 Codex > Claude Code > Cursor 选一个，不用填 key。一整轮交给你本机的 agent 跑，你的登录、`AGENTS.md` / `CLAUDE.md`、skills、MCP 都生效，md-render 的工具也能被它调用。Gemini CLI、Qwen Code、OpenCode、Ollama、LM Studio 能检测到，显示「即将支持」。
- **切换**：输入框旁的「来源 · 模型」按钮。本机 agent 的模型选「跟随默认」就是用它自己的配置；Claude Code 可选 sonnet / opus / haiku，Cursor 列出 `agent models` 的真实列表，其他名字在设置里填。每个来源单独记住选过的模型，重启后保留。
- **权限**：默认 bypass——agent 可以直接改工作目录里的文件、跑命令，不逐条确认。工作目录是当前文档所在的本地项目，没有就是内容库，不会是 home 或系统目录。每次改文件、跑命令都会显示成一个步骤并记进「活动」页；点停止会连它拉起的命令一起停掉。设置里打开**安全模式**后只允许改文件（Codex 在沙箱里跑）。
- **会话**：同一个会话里继续用同一个 agent 会接着上一轮聊；换了 agent 会提示「新会话开始」。
- **API 服务商**：MiniMax、DeepSeek、阿里百炼（通义千问）、自定义（OpenAI 兼容接口）。密钥走服务端代理，前端不接触。没检测到可用的本机 agent 时自动用它。

### 输入框里的两个符号

- **`@`** —— 挑文档带进对话作为上下文
- **`/`** —— 唤出技能列表

### `/` 技能清单

技能就是一个文件夹：`SKILL.md` 写给 AI 的要求，`agents/md-render.yaml` 声明出现在哪、能用哪些工具。app 自带的和你自己加的用同一种格式。

| 分组 | 技能 |
|---|---|
| AI 编辑部（AI 是编辑，不是作者） | `/编辑部审稿`（9 个编辑角色评审当前稿件）、`/标题分析`、`/发布复盘` |
| 平台版本 | `/公众号版`、`/小红书版`、`/知乎版`（文档工具栏「平台版」下拉里也有） |
| 改写 | `/标题建议`、`/提纲`、`/扩写`、`/续写`、`/润色`、`/压缩`、提炼要点 |
| 内容管理 | `/选题`、`/新稿件`、`/资料单`、`/待发布稿`、`/相关旧文`、`/工作区概览`、`/新建文件夹` |
| 今日速记 | `/今日任务`、`/今日笔记`、`/待办池`、`/整理今天` |
| 灵感白板 | `/白板流程图`、`/白板卡片` |
| 其它 | `/生成交付物`（另存为新文档并记住来源）、`/应用体检`（诊断运行环境并尝试安全修复） |

每个技能只能调用它声明过的工具；没声明的工具 AI 拿不到，硬调也会被拒绝。

**加一个自己的技能**：AI 助手 →「技能」页 →「新建 skill」，改模板里的说明和 `label`，保存后马上出现在 `/` 列表里，不用重启。也可以直接在 `~/Documents/MdRender/.agents/skills/<名字>/` 下放文件。想改内置技能，点它的「编辑」，会先复制一份到内容库，之后用你的版本。

**PDF→Word、视频→音频** 不需要 AI，已经挪到文件树的右键菜单里。

### 编辑部记忆

复盘的结论会累积下来，后续审稿时自动带上——你的风格偏好、踩过的坑、什么标题在你的号上有效。

### 改稿是「先看后应用」

AI 改正文、删条目都不会直接生效，而是生成一条**待确认改动**：当前文档会出现 diff，顶栏的收件箱（带数字）里能看到所有待确认的改动，在任何界面都能展开 diff、应用或放弃。AI 读完稿子后如果你又手动改了，它提交的改动会被拒绝，让它重新读。

AI 助手的「活动」页按天列出所有 AI 操作（app 里的 AI、外部 AI、在 app 外改了文件），可以只看改动类。

### 三种用 AI 的方式

| 方式 | 适合 | 怎么接 |
|---|---|---|
| **app 里的 AI 助手** | 日常写稿 | 配好模型就能用 |
| **直接打开内容库**（Claude Code、Codex、Cursor 等） | 想用自己的 agent | 用它打开 `~/Documents/MdRender`。app 会在这里维护 `AGENTS.md`（目录约定和规则）和 `.agents/skills/`（技能，`.claude/skills` 指向它），app 不开也能用 |
| **MCP**（Claude Desktop 等） | 只能通过 MCP 接的客户端，或需要 app 专属能力（全文搜索、排版渲染、收件箱） | 见下一节 |

### 让别的 AI 操作这个 app（MCP）

启动桌面版后会开一个只绑 `127.0.0.1` 的控制桥，配好后 **Claude Desktop、Cursor 等 MCP 客户端可以直接操作这个 app**——读写文档、搜索、改元数据、建稿件、切界面、往画布加卡片、渲染公众号排版。

能用哪些工具按风险分级决定：读、导航、可逆的写（新建、改元数据、移动、重命名）直接执行；改正文和删除会生成待确认改动，进收件箱等你处理；重建 / 清空白板和安全修复不对外。AI 面板关着也能用。设置 → 外部 agent 接入里可以一键复制 MCP 配置。

配置方法见 [`server/mcp-bridge/README.md`](../server/mcp-bridge/README.md)。首次使用需要 `cd server/mcp-bridge && npm install`。

## 导出

单篇文档可导出为 **Markdown、HTML、PDF、DOCX**。
微信公众号走单独的**格式化复制**：预览弹窗里选模板，复制出来的样式全部内联（公众号不支持外部 CSS），粘进后台即可。

---

## 桌面版 vs Web 版

| 能力 | 桌面版（Electron） | Web 版 |
|---|---|---|
| 数据存储 | SQLite；迁移后是 `~/Documents/MdRender` 下的 Markdown / JSON Canvas 文件 | `localStorage` |
| 全文搜索 | FTS5 索引正文 | 关键词匹配 |
| 本地 `.md` 磁盘同步 | ✅ | 受限（依赖浏览器 File System API） |
| MCP 控制桥 | ✅ | ❌ |
| 内容库技能、迁移到文件 | ✅ | ❌（只有内置技能） |
| 其余功能 | 一致 | 一致 |
