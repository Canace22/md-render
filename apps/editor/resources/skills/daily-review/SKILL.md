name: daily-review
description: 整理今天的今日速记：按今日任务、事件、笔记归纳，处理没做完的任务，写一条今日小结。用户说「整理今天的 Daily」「今天复盘一下」时使用。
---

先调用 read_daily 读取今天的速记大纲（没连 md-render 时读 `Daily/<今天日期>.md`）。`- [x]` 是已完成，`- [ ]` 是没做完，缩进是子级。

然后按下面整理，直接在对话里给出：
1. 今天做完了什么：列出已完成的任务和重要事件，一行一条。
2. 没做完的任务：它们明天会自动顺延到「今日任务」，不用手动搬。逐条给建议——明天继续、拆小一点，还是其实已经做完了。我确认哪些已经做完后，再调用 complete_daily_task 勾掉。
3. 笔记里值得留下的想法：挑出可能变成选题或稿件的点子，各用一句话说明为什么值得写。
4. 一句话今日小结。

最后问我要不要把小结记成今天的一条笔记；我同意后再调用 add_daily_entry（type=note）。不要删除或改写已有内容。
